# Coolinar (Меню недели) — Android

Современное Android-приложение для планирования питания, ведения запасов холодильника, каталогизации рецептов, интерактивной готовки и формирования списка покупок.

## Стек технологий
- **Kotlin + Jetpack Compose** — декларативный UI на базе Material 3 с поддержкой динамических цветов (Dynamic Color на Android 12+).
- **Чистая архитектура (Clean Architecture)**:
  - `domain` — чистые модели, интерфейсы репозиториев и Use Cases (бизнес-логика без привязки к фреймворкам).
  - `data` — локальная база данных Room, работа с хранилищем, сетевая синхронизация и реализации репозиториев.
  - `presentation` — экраны на Compose, StateFlow-модели (ViewModel), дизайн-система и навигация.
  - `di` — модули внедрения зависимостей Dagger Hilt (`com.shvarsman.coolinar.di`).
- **Офлайн-хранение (Offline-first)** — Room Database для мгновенного отклика и полной автономности без интернета.
- **Облако и синхронизация** — Firebase Authentication (авторизация по почте/паролю и гостевой режим), Cloud Firestore (двусторонняя синхронизация между устройствами), Firebase Storage (загрузка фото).
- **Навигация** — Jetpack Navigation Compose с плавными анимированными переходами между вкладками.
- **Изображения** — Coil 3 для асинхронной загрузки и локального кэширования фотографий рецептов и аватаров.

## Основной функционал

- **Холодильник**:
  - Учёт наличия продуктов, их количества, единиц измерения и сроков годности.
  - Умный поиск с дебаунсом, группировка и фильтрация по категориям продуктов.
  - Множественный выбор позиций и оптимистичное удаление с возможностью отмены (Snackbar Undo).
- **Рецепты**:
  - Создание и редактирование рецептов: фото обложки, категории, метод приготовления, уровень сложности и время.
  - Пошаговые инструкции с возможностью прикрепления фотографий к каждому шагу и встроенными кулинарными таймерами.
  - Выбор ингредиентов из общего каталога или с быстрым фильтром **«В холодильнике»**.
  - Автоматический пересчёт пропорций ингредиентов при изменении количества порций.
  - Визуальные индикаторы доступности ингредиентов на основе текущих остатков в холодильнике.
- **Меню на неделю**:
  - Составление рациона по дням недели и типам приёма пищи (завтрак, обед, ужин, перекус).
  - Индикация нехватки продуктов для запланированных блюд.
- **Список покупок**:
  - Автоматическое формирование списка недостающих продуктов при назначении рецептов в меню.
  - Ручное добавление товаров из каталога.
  - Перемещение купленных продуктов прямо в холодильник в один клик.
- **Пошаговый режим готовки**:
  - Интерактивный кулинарный режим с крупными элементами управления, таймерами шагов и адаптивным статусом готовности блюда.
- **Каталог продуктов**:
  - Встроенная библиотека продуктов с категориями, мерами измерения и векторными иконками.
  - Возможность добавления собственных продуктов.
- **Профиль и облако**:
  - Авторизация через Firebase, синхронизация данных пользователя, редактирование профиля и аватара.
  - Экспорт и импорт локальных резервных копий (ZIP).
- **Онбординг и маскот**:
  - Стартовый онбординг с выбором режима использования (с аккаунтом или гостевой).
  - Интерактивный тур с живыми подсказками маскота Кулинара на ключевых экранах.

## Как запустить проект
1. Открыть каталог проекта в Android Studio (Koala Feature Drop 2024.1.2 или новее).
2. Дождаться автоматической синхронизации Gradle.
3. Запустить сборку на эмуляторе или физическом устройстве с Android 7.0+ (minSdk 24).
